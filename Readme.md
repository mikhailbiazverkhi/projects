### 1. Telecom Automation System (Linux / Asterisk / C)

**Technologies:** Linux (CentOS), Asterisk PBX, C, VirtualBox, GSM modem  

#### Problem
The company needed an automated way to decode DTMF audio signals received through phone calls.

#### Architecture
Mobile Phone
↓
GSM Modem (USB)
↓
VirtualBox
↓
CentOS Linux
↓
Asterisk PBX
↓
Custom C Module
↓
Decoder
↓
SMS Response

#### Responsibilities
- Configured GSM modem pipeline  
- Implemented USB passthrough to Linux virtual machine  
- Modified C source code to extract decoded digits into a text file  
- Rebuilt Linux distribution to persist system-level modifications  
- Automated SMS response for verification  

#### Result
Fully automated telecommunication decoding system.  
Director personally tested the system and confirmed successful end-to-end processing.
